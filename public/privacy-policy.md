# プライバシーポリシー

最終更新日: 2025年1月

## はじめに

本プライバシーポリシーは、Dyson Sphere Program 生産チェーン計算機（以下「本サービス」）における個人情報の取り扱いについて説明します。

## 収集する情報

本サービスでは、以下の情報を収集する場合があります：

### フィードバックフォーム

- フィードバックのタイトルと内容
- カテゴリ（機能追加、データ訂正、UI改善、バグ報告、その他）
- 連絡先情報（任意入力：メールアドレスまたはGitHubユーザー名）

### 自動収集情報

- ブラウザの種類とバージョン
- 使用しているデバイスの種類
- IPアドレス（ログに記録される場合があります）

## 情報の使用目的

収集した情報は、以下の目的で使用します：

- サービスの改善と機能追加
- バグの修正と問題解決
- ユーザーからの問い合わせへの対応
- サービス品質の向上

## 情報の公開範囲

### GitHub Issuesへの公開

フィードバックフォームから送信された情報は、GitHub Issuesとして公開されます。以下の情報が公開される可能性があります：

- フィードバックのタイトルと内容
- カテゴリ情報
- 連絡先情報（入力された場合）

**注意**: GitHub Issuesは公開リポジトリで、インターネット上の誰でも閲覧可能です。機密情報や個人を特定できる情報は含めないでください。

## 情報の保存期間

- フィードバック情報: GitHub Issuesとして永続的に保存されます
- 自動収集情報: ログとして1ヶ月程度保存されます

## データの削除

個人情報の削除を希望する場合は、GitHub Issuesでお問い合わせください。ただし、GitHub Issuesの削除は技術的な制約により困難な場合があります。

## クッキー及びローカルストレージ

本サービスでは、以下の目的でブラウザのローカルストレージを使用します：

- ユーザー設定の保存（言語設定、テンプレート設定など）
- プラン情報の保存（ユーザーが明示的に保存した場合のみ）

これらの情報はユーザーのブラウザにのみ保存され、サーバーに送信されることはありません。

## 第三者サービス

本サービスは以下の第三者サービスを使用しています：

- **GitHub**: フィードバックの管理とコードのホスティング
- **Vercel / Netlify**: サービスのホスティング（使用している場合）

これらのサービスのプライバシーポリシーもご確認ください。

## お問い合わせ

プライバシーに関するご質問やご要望は、GitHub Issuesにお問い合わせください。

## プライバシーポリシーの変更

本プライバシーポリシーは、事前の通知なく変更される場合があります。重要な変更がある場合は、GitHubのリリースノートでお知らせします。
