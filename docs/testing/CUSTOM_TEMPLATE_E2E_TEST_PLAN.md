# ユーザー定義テンプレート機能 - E2Eテスト項目書

## アプリケーション概要

DSP生産計算機のユーザー定義テンプレート機能は、ユーザーが現在のグローバル設定をテンプレートとして保存・管理し、複数のプレイスタイル（省電力モード、コンパクトモード、高速モードなど）を素早く切り替えるための機能です。

**主な機能:**

- **テンプレート作成**: 現在の設定をテンプレートとして保存（名称・メモ付き）
- **テンプレート一覧表示**: デフォルトテンプレートとカスタムテンプレートの区別表示
- **テンプレート適用**: 確認モーダル付きでテンプレートを適用
- **テンプレート編集**: 名称・メモの変更、現在の設定での上書き
- **テンプレート削除**: 確認モーダル付きで削除
- **同名チェック**: 同名テンプレート作成時の差分表示と上書き確認
- **履歴連携**: テンプレート操作の履歴記録と復元（undo/redo）
- **永続化**: LocalStorageへの保存とページリロード後の復元

### 1. テンプレート作成機能

**シード**: `tests/e2e/seed.spec.ts`

#### 1.1 新規テンプレート作成（正常系）

**ステップ:**

1. アプリケーションを起動し、初期状態を確認
2. 設定パネルのカスタムテンプレートセクションを表示
3. 「＋ テンプレート作成」ボタンをクリック
4. テンプレート作成モーダルが表示されることを確認
5. テンプレート名入力フィールドに「省電力モード」と入力
6. メモ入力フィールドに「電力消費を最小化する設定」と入力
7. 現在の設定プレビューが表示されることを確認（コンベアベルト、ソーター、増産剤、各生産設備などの設定）
8. 「保存」ボタンをクリック
9. モーダルが閉じることを確認
10. カスタムテンプレートセクションに「省電力モード」テンプレートカードが表示されることを確認

**期待結果:**

- テンプレート作成モーダルが正しく表示される（`data-testid="create-template-modal"`）
- テンプレート名とメモが正しく入力できる
- 現在の設定プレビューが表示される（`data-testid="template-settings-preview"`）
- 保存後、カスタムテンプレートリストに新しいテンプレートが追加される
- テンプレートカードに名称とメモが表示される
- 空状態メッセージが非表示になる

**テスト用識別子:**

- `create-custom-template-button`: テンプレート作成ボタン
- `create-template-modal`: 作成モーダル

#### 3.4 設定差分の詳細表示

**ステップ:**

2. 一部の設定を変更（例: コンベアベルトをMk.1に、増産剤を「なし」に）
3. テンプレート「フルセットアップ」の「適用」ボタンをクリック
4. 適用確認モーダルで以下の差分が表示されることを確認:
   - コンベアベルト（階層、積載数）
   - ソーター（階層）
   - 増産剤（種類、モード）
   - 増産剤倍率（デフォルト以外の場合のみ: 生産倍率、速度倍率）
   - 機械ランク（製錬設備、組立機、化学プラント、マトリックスラボ）
   - 採掘速度研究（ボーナス値）
   - 代替レシピ（設定されている場合のみ: 件数）
   - 光子生成設定（設定されている場合のみ: 重力レンズ使用、レイ伝送効率、重力レンズ増産剤）
5. 各設定項目がi18n対応のラベルで表示されることを確認

**期待結果:**

- すべての設定項目の差分が表示される
- 機械ランクは日本語ラベル（「アーク溶鉱炉」「再構成式組立機」など）で表示される
- 精製設備（Refine）と小型粒子衝突型加速器（Particle）は固定ランクのため表示されない
- デフォルト値と同じ項目も表示される（仕様通り）
- i18n対応で多言語表示が正しい

8. テンプレート名が「タブテスト-更新」に更新されていることを確認

**期待結果:**

- LocalStorageを共有するため、タブ間でデータが同期される
- リロード後に最新の状態が反映される

## テストデータ管理

### テスト前のクリーンアップ

各テストケースの実行前に、LocalStorageをクリアして初期状態に戻すこと。

```typescript
await page.evaluate(() => {
  localStorage.clear();
});
await page.reload();
```

### テスト用データの準備

複数のテンプレートが必要な場合、テストヘルパー関数を使用して効率的にデータを準備する。

```typescript
async function createCustomTemplate(page, name: string, note?: string) {
  await page.getByTestId("create-custom-template-button").click();
  await page.getByTestId("template-name-input").fill(name);
  if (note) {
    await page.getByTestId("template-note-input").fill(note);
  }
  await page.getByTestId("create-template-save-button").click();
}
```
