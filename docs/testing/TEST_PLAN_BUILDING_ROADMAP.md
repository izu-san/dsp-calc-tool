# 建設ロードマップ機能 - テスト計画書

## アプリケーション概要

DSP生産計算機の建設ロードマップ機能は、計算された生産チェーンを実際のゲーム内で構築する際に、段階的な建設計画をチェックリスト形式で表示・管理する機能です。生産ツリーの階層に基づいて自動的にフェーズを分割し、原材料から最終製品まで段階的に建設を進められるようガイドします。

**主な機能**:

- フェーズ分割による段階的建設ガイド
- チェックリスト形式の進捗管理
- 全体進捗とフェーズ別進捗の可視化
- アコーディオン形式のUI
- ローカルストレージへの永続化

**アクセス方法**: http://localhost:5173/ → レシピ選択 → 建設ロードマップタブ

## テストシナリオ

### 1. 基本表示とナビゲーション

**前提条件**: ローカル開発サーバーが起動している

#### 1.1 初回アクセス時の表示

**ステップ**:

1. ブラウザで http://localhost:5173/ にアクセス
2. ウェルカムモーダルが表示された場合は「スキップ」をクリック
3. レシピ一覧から「電磁マトリックス」を選択
4. 「建設ロードマップ」タブをクリック

**期待結果**:

- 建設ロードマップビューが表示される
- 「建設ロードマップ」という見出しが表示される
- 「全体進捗: 0%」が表示される
- 複数のフェーズ（Phase）がアコーディオン形式で表示される
- 最初のフェーズ「原材料採掘」が展開状態で表示される
- 他のフェーズ（Phase 2以降）は折りたたまれている
- 「すべてリセット」ボタンが表示される

#### 1.2 タブ間の切り替え

**ステップ**:

1. 電磁マトリックスのレシピで計算を実行済みの状態から開始
2. 「統計」タブをクリック
3. 「建設ロードマップ」タブをクリック
4. 「生産チェーン」タブをクリック
5. 再度「建設ロードマップ」タブをクリック

**期待結果**:

- 各タブ間でスムーズに切り替わる
- ロードマップタブに戻ったときに以前の状態が保持されている
- アクティブなタブが視覚的にハイライトされる

#### 1.3 異なるレシピでの表示

**ステップ**:

1. 「鉄インゴット」レシピを選択
2. 「建設ロードマップ」タブを開く
3. フェーズ数とノード数を確認
4. 「構造マトリックス」レシピを選択
5. 「建設ロードマップ」タブを開く
6. フェーズ数とノード数を確認

**期待結果**:

- レシピの複雑度に応じてフェーズ数が変わる
- 鉄インゴット: シンプルな構造（2フェーズ程度）
- 構造マトリックス: 複雑な構造（4フェーズ以上）
- 各レシピで適切なフェーズタイトルが生成される
