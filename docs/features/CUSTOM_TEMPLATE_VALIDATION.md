# カスタムテンプレート名のバリデーション仕様

## 概要

テンプレート新規作成時のテンプレート名のバリデーション仕様を記載します。

## バリデーションロジック

1. **空白トリム**: `templateName.trim()` で前後の空白を除去
2. **必須チェック**: トリム後の文字列が空でないこと
3. **全角スペースのみチェック**: トリム後の文字列から全角スペース（`U+3000`）を除去した結果が空でないこと
4. **長さチェック**: 1〜40文字以内であること
5. **前後空白チェック**: 元の入力値とトリム後の値が一致すること（前後に空白を含めない）
6. **重複チェック**: 既存のテンプレート名と重複しないこと（重複時は上書き確認モーダル表示）

| `"Test\u2000Template"` | `"Test\u2000Template"` | ✅ **正常** | 中央の en quad は許可（JavaScript の `trim()` は削除しない）                |
| `"Test\u3000Template"` | `"Test\u3000Template"` | ✅ **正常** | 中央の全角スペースは許可                                                    |

**注意**: JavaScript の `trim()` メソッドは、以下の文字のみを削除します：

- 半角スペース（`U+0020`）
- タブ（`U+0009`）
- 改行（`U+000A`）
- 復帰（`U+000D`）

全角スペース（`U+3000`）やノンブレーキングスペース（`U+00A0`）などは削除されません。そのため、全角スペースのみの入力は別途チェックが必要です。

## バリデーション実行順序

1. **空白トリム**: `trimmedName = templateName.trim()`
2. **必須チェック**: `if (!trimmedName)` → エラー: "テンプレート名 は必須です"
3. **全角スペースのみチェック**: `if (trimmedName.replace(/　/g, "") === "")` → エラー: "テンプレート名 は必須です"
4. **長さチェック**: `if (trimmedName.length < 1 || trimmedName.length > 40)` → エラー: "テンプレート名 は1〜40文字で入力してください"
5. **前後空白チェック**: `if (templateName !== trimmedName)` → エラー: "テンプレート名 の前後には空白を含めないでください"
6. **重複チェック**: 既存テンプレート名との比較 → 重複時は上書き確認モーダル表示

## 実装コード（参考）

```typescript
const handleCreateConfirm = () => {
  const trimmedName = templateName.trim();
  if (!trimmedName) {
    setNameError(t("templateName") + " は必須です");
    return;
  }
  // 全角スペースのみのチェック（trim()では削除されないため）
  if (trimmedName.replace(/　/g, "") === "") {
    setNameError(t("templateName") + " は必須です");
    return;
  }
  if (trimmedName.length < 1 || trimmedName.length > 40) {
    setNameError(t("templateName") + " は1〜40文字で入力してください");
    return;
  }
  if (templateName !== trimmedName) {
    setNameError(t("templateName") + " の前後には空白を含めないでください");
    return;
  }

  // 重複チェック
  const existingTemplate = Object.values(customTemplates || {}).find(
    t => t.meta.name === trimmedName
  );
  if (existingTemplate) {
    setOverwriteTargetId(existingTemplate.meta.id);
    setShowOverwriteConfirm(true);
    return;
  }

  try {
    createCustomTemplate(trimmedName, templateNote.trim() || undefined);
    // ... 成功処理
  } catch (error) {
    // ... エラーハンドリング
  }
};
```
