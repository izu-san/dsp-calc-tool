# ヘッダーUI/UX改善仕様書

## 1. 概要

### 1.1 目的

ヘッダーに配置されているボタンが増加し、視認性と操作性が低下している問題を解決するため、UI/UXを改善する。

### 1.2 現状の問題点

- ヘッダー右側に6-7個のボタンが横並びで配置されており、視認性が悪い
- ボタンが多すぎてレスポンシブ対応（モバイル表示）時にレイアウトが崩れる可能性がある
- 機能グループの関連性が視覚的に伝わらない
- 各ボタンの役割が明確でない（アイコンとテキストの組み合わせが不統一）

### 1.3 改善目標

- 視認性の向上：ボタンを機能グループごとに整理し、視認しやすいレイアウトにする
- 操作性の向上：頻繁に使用する機能を優先的に配置し、アクセスしやすくする
- レスポンシブ対応：モバイル表示でも使いやすいUIを提供する
- 一貫性の確保：既存のデザインシステムに準拠した統一的なUIを提供する

## 2. 現状の構成

### 2.1 現在のヘッダー構造

```
┌─────────────────────────────────────────────────────────────┐
│ Dyson Sphere Program - レシピ計算機                          │
│                        [↶] [↷] [📜] [🇯🇵▼] [💾] [📂] [🔗] │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 配置されているコンポーネント

#### 左側

- **タイトル**: `Dyson Sphere Program - レシピ計算機` (固定)

#### 右側（現在の順序）

1. **HistoryControls**: `↶ 元に戻す` / `↷ やり直し` / `📜 履歴` (3ボタン)
2. **LanguageSwitcher**: `🇯🇵 日本語` / `🇺🇸 English` (セレクトボックス)
3. **PlanManager**: `💾 保存` / `📂 読み込み` / `🔗 URL共有` (3ボタン)

**合計**: 6-7個のUI要素が横並び

## 3. 改善案

### 3.1 基本方針

1. **機能グループ化**: 関連する機能を1つのドロップダウンメニューまたはツールバーにまとめる
2. **優先度の明確化**: 頻繁に使用する機能（Undo/Redo）は直接アクセス可能にし、使用頻度が低い機能（保存/読み込み）はメニュー内に配置
3. **レスポンシブ対応**: モバイル表示時はハンバーガーメニューに統合
4. **視覚的階層**: 重要な機能は目立つように、補助的な機能は控えめに

### 3.2 提案1: ドロップダウンメニュー方式（推奨）

#### 3.2.1 レイアウト構造

```
┌─────────────────────────────────────────────────────────────┐
│ Dyson Sphere Program - レシピ計算機                          │
│                       [↶] [↷] [📜] [💾▼] [🌐▼] [🇯🇵▼] │
└─────────────────────────────────────────────────────────────┘
```

#### 3.2.2 機能グループ

**グループ1: 履歴操作（直接アクセス）**

- `↶ 元に戻す` (Undo) - ショートカット: Ctrl+Z
- `↷ やり直し` (Redo) - ショートカット: Ctrl+Y / Ctrl+Shift+Z
- `📜 履歴` (History Dialog) - クリックで履歴ダイアログを開く

**グループ2: プランマネージャー（ドロップダウン）**

- トリガー: `💾 保存` ボタン（クリックでドロップダウン）
- メニュー項目:
  - `💾 保存` (Save to LocalStorage)
  - `📂 読み込み` (Load from LocalStorage)
  - `🔗 URL共有` (Share URL)
  - 区切り線
  - `📤 エクスポート` (Export as JSON/Markdown/CSV/Excel/Image)
  - `📥 インポート` (Import from File)

**グループ3: 言語切替（ドロップダウン）**

- トリガー: `🌐` アイコンまたは現在の言語表示（クリックでドロップダウン）
- メニュー項目:
  - `🇯🇵 日本語`
  - `🇺🇸 English`

#### 3.2.3 実装詳細

##### PlanManagerの統合

- `💾 保存` ボタンをクリックでドロップダウンメニューを表示
- Radix UI `DropdownMenu` コンポーネントを使用
- メニュー内に「保存」「読み込み」「URL共有」「エクスポート」「インポート」を配置

##### LanguageSwitcherの改善

- セレクトボックスからドロップダウンメニューに変更
- グローバルアイコン（🌐）または現在の言語フラグをトリガーとして使用
- Radix UI `DropdownMenu` コンポーネントを使用

##### レスポンシブ対応

- ブレークポイント: `sm: 640px` / `md: 768px` / `lg: 1024px`
- `md` 未満: ヘッダー右側に「メニュー」ボタンを表示し、クリックで全機能をドロワー形式で表示
- `md` 以上: 上記のレイアウトを適用

### 3.3 提案2: ツールバー方式（代替案）

#### 3.3.1 レイアウト構造

```
│ Dyson Sphere Program - レシピ計算機                          │
│                       [↶↷📜] [💾📂🔗] [🌐] [🇯🇵] │

```

#### 3.3.2 機能グループ

**グループ1: 履歴ツールバー**

- `↶` / `↷` / `📜` を1つのツールバーにまとめる
- ボタン間の間隔を狭くし、視覚的にグループ化

**グループ2: プランツールバー**

- `💾` / `📂` / `🔗` を1つのツールバーにまとめる
- ボタン間の間隔を狭くし、視覚的にグループ化

**グループ3: 言語切替**

- アイコンのみ表示（ホバーまたはクリックでツールチップ表示）

### 3.4 提案3: ハンバーガーメニュー方式（モバイル重視）

## 4. 推奨実装（提案1: ドロップダウンメニュー方式）

### 4.1 コンポーネント構成

```
Header/
├── index.tsx                    # メインヘッダーコンポーネント
├── HistoryToolbar.tsx           # 履歴操作ツールバー（↶↷📜）
├── PlanManagerMenu.tsx          # プランマネージャードロップダウン
├── LanguageMenu.tsx             # 言語切替ドロップダウン
└── MobileMenu.tsx               # モバイル用ハンバーガーメニュー
```

### 4.2 各コンポーネントの仕様

#### 4.2.1 HistoryToolbar.tsx

- **役割**: 履歴操作（Undo/Redo/History）を提供
- **配置**: ヘッダー右側、最も左
- **スタイル**: 既存の `HistoryControls` と同様のスタイルを維持
- **機能**:
  - `↶ 元に戻す`: Undo操作（既存の実装を流用）
  - `↷ やり直し`: Redo操作（既存の実装を流用）
  - `📜 履歴`: 履歴ダイアログを開く（既存の実装を流用）

#### 4.2.2 PlanManagerMenu.tsx

- **役割**: プラン管理機能をドロップダウンメニューで提供
- **トリガー**: `💾 保存` ボタン（既存のアイコンとテキストを維持）
- **メニュー構造**:
  ```
  💾 保存
  📂 読み込み
  🔗 URL共有
  ────────────
  📤 エクスポート...
    → JSON
    → Markdown
    → CSV
    → Excel
    → 画像
  📥 インポート...
    → ファイル選択ダイアログ
  ```
- **実装**: Radix UI `DropdownMenu` を使用
- **スタイル**: 既存の `PlanManager` のスタイルを維持しつつ、メニューは統一的なデザイン

#### 4.2.3 LanguageMenu.tsx

- **役割**: 言語切替をドロップダウンメニューで提供
- **トリガー**: `🌐` アイコンまたは現在の言語表示（`🇯🇵 日本語` / `🇺🇸 English`）
- **メニュー構造**:
  ```
  🇯🇵 日本語
  🇺🇸 English
  ```
- **実装**: Radix UI `DropdownMenu` を使用
- **スタイル**: 既存の `LanguageSwitcher` のスタイルを維持しつつ、メニューは統一的なデザイン

#### 4.2.4 MobileMenu.tsx

- **役割**: モバイル表示時に全機能をドロワー形式で提供
- **トリガー**: ハンバーガーメニューアイコン（☰）
- **表示内容**:
  - 履歴操作セクション
  - プラン管理セクション
  - 言語切替セクション
- **実装**: Radix UI `Sheet`（ドロワー）を使用
- **表示条件**: `md` ブレークポイント未満（`< 768px`）

### 4.3 レイアウト詳細

#### デスクトップ表示（`md` 以上: `≥ 768px`）

```
┌─────────────────────────────────────────────────────────────┐
│ Dyson Sphere Program - レシピ計算機                          │
│                                                              │
│                                    [↶] [↷] [📜] [💾▼] [🌐▼] │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

- 要素間の間隔: `gap-3` (12px)
- ボタンサイズ: 既存と同様（`px-4 py-2`）
- ドロップダウンメニューの幅: `min-w-[200px]`

#### モバイル表示（`md` 未満: `< 768px`）

```
┌─────────────────────────────────────────────────────────────┐
│ Dyson Sphere Program - レシピ計算機                  [☰] │
└─────────────────────────────────────────────────────────────┘
```

- ハンバーガーメニューをクリックでドロワーを表示
- ドロワー幅: `w-[280px]`
- ドロワー内のセクション間隔: `gap-6`

### 4.4 スタイルガイドライン

#### 4.4.1 カラーパレット（既存のテーマを維持）

- **履歴操作**:
  - Undo: `neon-blue` (`bg-neon-blue/30`, `border-neon-blue/50`)
  - Redo: `neon-purple` (`bg-neon-purple/30`, `border-neon-purple/50`)
  - History: `dark-600` (`bg-dark-600/50`, `border-neon-blue/30`)
- **プラン管理**: `neon-green` (`bg-neon-green/30`, `border-neon-green/50`)
- **言語切替**: `neon-cyan` (`bg-neon-cyan/30`, `border-neon-cyan/40`)

#### 4.4.2 ドロップダウンメニューのスタイル

- 背景: `bg-dark-700/95 backdrop-blur-md`
- ボーダー: `border-2 border-neon-blue/40`
- 影: `shadow-[0_0_30px_rgba(0,136,255,0.3)]`
- メニュー項目: `px-4 py-2 hover:bg-dark-600/50`
- 区切り線: `border-t border-neon-blue/20`

#### 4.4.3 ホバー・アクティブ状態

- ホバー: `hover:bg-[color]/40 hover:border-[color] hover:shadow-[0_0_15px_rgba(...)]`
- 無効: `disabled:bg-dark-600 disabled:border-[color]/20 disabled:text-space-400`
- トランジション: `transition-all`

### 4.5 インタラクション仕様

#### 4.5.1 ドロップダウンメニューの動作

- トリガーをクリック: メニューを開く/閉じる
- メニュー外をクリック: メニューを閉じる
- ESCキー: メニューを閉じる
- キーボードナビゲーション: 矢印キーで項目を移動、Enterで選択

#### 4.5.2 ショートカットキー（既存を維持）

- `Ctrl+Z` / `Cmd+Z`: Undo
- `Ctrl+Y` / `Cmd+Y` または `Ctrl+Shift+Z`: Redo
- 他のショートカットは現時点では追加しない

#### 4.5.3 アニメーション

- ドロップダウンメニュー: `animate-fadeInScale`（既存のアニメーションを使用）
- ボタンホバー: `hover:scale-105`（既存のアニメーションを使用）
- トランジション: `transition-all`

4. レスポンシブ表示を各種デバイスで確認

## 7. 既存機能への影響

### 7.1 互換性

- 既存の機能はすべて維持される（見た目と操作方法のみ変更）
- ショートカットキーは既存のものを維持
- データの永続化（localStorage）への影響なし

### 7.2 マイグレーション

- 既存のコンポーネント（`HistoryControls`, `LanguageSwitcher`, `PlanManager`）は段階的に置き換え
- 既存のテストは更新が必要だが、テスト対象の機能は変わらない

## 8. 将来の拡張性

### 8.1 拡張可能なポイント

- メニュー項目の追加（将来的に機能が増えた場合）
- ショートカットキーの追加
- カスタマイズ可能なメニュー順序（ユーザー設定）

### 8.2 考慮事項

- メニュー項目が増えた場合のレイアウト調整
- 多言語対応（現在は日本語・英語のみ）
